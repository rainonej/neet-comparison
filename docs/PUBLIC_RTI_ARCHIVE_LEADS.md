# Public RTI archive leads

The Ministry of Education publishes an index of historical RTI requests. The archive often preserves the request text while reply attachments or transfer records are inconsistently linked. These request numbers are useful discovery keys for contacting the ministry, NTA, or the original applicant and for searching web archives.

## Retrieval procedure

1. Search the exact request number on the Ministry of Education RTI archive.
2. Record every `View`, appeal, transfer, or attachment URL.
3. Check the Internet Archive or government web cache for dead attachments.
4. Search the request number verbatim in general search engines and social media.
5. Ask the ministry for a copy of the historical reply and transfer memo, referring to the existing request number rather than filing the whole substantive request again.
6. When an original applicant can be identified lawfully, ask whether they retained the reply and whether a redacted copy may be shared.

The archive proves that the information was requested; it does not prove that it was provided or that a reply contains usable data.
